About

Hi, I'm Adam Kjær Persson, also known as sovepose40. I'm a game developer from Denmark.

I mainly work independently and enjoy rapidly prototyping game ideas and mechanics to see what works.

Most of my game development is done in Unreal Engine 5 using Blueprints. I also create models, animations and other assets in Blender.

A lot of my projects start as small experiments. When an idea feels interesting enough, I develop it further into a more complete game.

Unreal Engine 5 / Blueprints / Blender / GIMP / Aseprite / DaVinci Resolve / Audacity / Git
